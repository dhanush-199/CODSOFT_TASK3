\# Nginx Web Server Deployment



\## CodSoft DevOps Internship - Task 3



This project demonstrates the deployment of a static website using the Nginx web server on Ubuntu through WSL.



\## 📌 Project Overview



The project includes:



\- Nginx installation and configuration

\- Static website hosting

\- Custom Nginx server configuration

\- Custom 404 error page

\- Website testing using a web browser

\- HTTP response testing using `curl`



\## 🛠 Technologies Used



\- Ubuntu

\- WSL

\- Nginx

\- HTML

\- Git

\- GitHub
